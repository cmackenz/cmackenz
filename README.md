# Craig MacKenzie

Front-end developer in Toronto with 20+ years of experience building web applications.

I'm good at taking complicated workflows and making them straightforward to use. I work through how an interface should behave, build it, and pay attention to the details that make it feel right. UX is a big part of how I approach development.

Most days I work in Ember and Rails. I also work with React, Vue, and TypeScript, depending on the project. I'm comfortable getting into the back end when a feature needs it, but the front end is where I do my best work.

I care about building software people actually enjoy using. That means clear interactions, thoughtful defaults, and fewer things users have to figure out for themselves.

**Working with:** Ember.js · Rails · TypeScript · React · Vue · Postgres · Playwright
